# Changelog

## Unreleased

### Changed
- Requires `passport ^0.2` (the first published release of the core; `^0.1` matched no tag).

### Security
- Redis keys are prefix + the SHA-256 of the session ID, not the ID: reading the keys
  no longer gives live session IDs. Sessions stored before are not found (users log in
  again once).

### Changed
- Works with `orm` 0.1 and 0.2 (peer dependency `>=0.1 <0.3`); it uses only `orm.KeyValueStore`.
- The package is installed with gtr: `gtr.json` replaces `go.mod` (generated by gtr, not
  committed), and packages of the family are imported by their gtr names (`import "orm"`,
  `"orm/schema"`, `"orm-postgres"`, `"passport"`, …) instead of `github.com/shibisty/...`
  paths (ADR-0001, ADR-0002). Packages that plug into a core list it as a peer dependency.
  CI builds gtr-manager from source and runs `gtr install`.

Extracted from `github.com/youruser/goorm/auth/sessionstore/redisstore`.

### Breaking
- Module path is now `github.com/shibisty/passport.go-redis-session`.
- A TTL ≤ 0 is an error (previously the session never expired).

### Added
- `WithPrefix`.
- Tests: the shared `sessionstoretest` suite against a fake and against a live Redis.

### Fixed
- Redis errors are no longer reported as "session not found".
- A TTL below one second no longer turns into a never-expiring session.
- `Identity.Raw` is not stored in Redis.
